# Excel Data Analysis Practice
This repository contains my Excel practice work, including data structure and data cleaning exercises.

## Files Included

- `lesson1_six_orders_recreated.xlsx` — Six-order Excel practice.
- `lesson2_sales_cleaning_recreated.xlsx` — Sales data cleaning practice.

## What I Did

- Created a six-order Excel dataset.
- Cleaned sales data by removing the ₹ symbol.
- Converted numbers stored as text into numeric values.
- Used COUNT, COUNTA, and SUM to check the data.

## What I Found

- Before cleaning, COUNT returned 3 and SUM returned 600.
- After cleaning, COUNT returned 5 and SUM returned 1350.
- The ₹ symbol caused some sales values to be stored as text.
- Cleaning converted all five sales values into numeric values.
